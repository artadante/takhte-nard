# 🎲 راهنمای اتصال و استفاده از ماژول تخته نرد برای هوش مصنوعی (AI Integration Guide)

این پوشه حاوی هسته کامل، مستقل و تست‌شده **بازی تخته نرد سنتی ایرانی** (به همراه هوش مصنوعی حریف، تاس‌های ۳ بعدی، انیمیشن‌های فیزیکی مهره‌ها و قوانین کامل) است.  
این ماژول کاملاً **مستقل (Self-contained)** طراحی شده و هیچ وابستگی به منوها، تنظیمات پیچیده یا دیتابیس ندارد.

---

## 🚀 نحوه افزودن سریع به یک پروژه جدید (در ۳ مرحله)

### مرحله ۱: انتقال فایل‌های کد
کل این پوشه (`takhte-nard-core`) را در پروژه ری‌اکت جدید خود، داخل پوشه `src` کپی کنید:
```
your-new-project/
├── src/
│   └── takhte-nard-core/
│       ├── components/
│       ├── logic/
│       ├── assets/
│       ├── index.ts
│       └── AI_INSTRUCTIONS.md
```

### مرحله ۲: انتقال فایل‌های مدیا (عکس‌ها و صداها)
محتویات داخل پوشه `takhte-nard-core/assets/` را درون پوشه عمومی پروژه مقصد (`public/assets/`) قرار دهید:
- `public/assets/images/` (شامل عکس‌های بورد، مهره‌های سفید و سیاه و نشانگر تاس)
- `public/assets/sounds/` (شامل فایل‌های صوتی بازی)

> **نکته:** اگر تصاویر یا صداها در مسیر دیگری هستند، می‌توانید با پراپ `assetsBasePath` مسیر دلخواه را به کامپوننت بدهید.

### مرحله ۳: قرار دادن در صفحه و اجرا
در هر کجای پروژه که می‌خواهید بازی نمایش داده شود، کامپوننت `<BackgammonGame />` را اضافه کنید:

```tsx
import React from 'react';
import { BackgammonGame } from './takhte-nard-core';

export default function GamePage() {
  return (
    <div style={{ width: '100vw', height: '100vh' }}>
      <BackgammonGame
        playerName1="کاربر"
        playerName2="ربات هوشمند"
        aiDifficulty="standard" // یا "master" برای ربات فوق حرفه‌ای
        gameSpeed="fast"        // سرعت حرکت مهره‌های ربات
        isSoundEnabled={true}   // فعال بودن صداها
      />
    </div>
  );
}
```

## ⚙️ لیست کامل پراپ‌های کامپوننت `<BackgammonGame />`

| نام پراپ (Prop) | نوع داده (Type) | مقدار پیش‌فرض | توضیحات |
| :--- | :--- | :--- | :--- |
| `playerName1` | `string` | `'شما (سفید)'` | نام بازیکن کاربر (مهره‌های سفید) |
| `playerName2` | `string` | `'کامپیوتر (سیاه)'` | نام ربات حریف (مهره‌های سیاه) |
| `aiDifficulty` | `'standard' \| 'master'` | `'standard'` | درجه سختی ربات (استاندارد یا گرندمستر) |
| `gameSpeed` | `'fast' \| 'slow'` | `'fast'` | سرعت حرکت و مکث بین حرکات ربات |
| `isSoundEnabled` | `boolean` | `true` | فعال یا بی‌صدا بودن افکت‌های صوتی |
| `boardTheme` | `'classic' \| 'wood' \| 'marble'` | `'classic'` | تم ظاهری تخته |
| `assetsBasePath` | `string` | `'./assets'` | آدرس پوشه حاوی پوشه‌های `images` و `sounds` |
| `onGameOver` | `(winner, victoryType) => void` | `undefined` | تابعی که هنگام برد صدا زده می‌شود |
| `className` | `string` | `''` | کلاس‌های دلخواه CSS والد |

## 📂 ساختار فایل‌ها و معماری داخلی

- **`components/`**
  - `BackgammonGame.tsx`: کامپوننت مادر، رابط کاربری کامل شامل تخته، نوار اطلاعات بازیکنان، شمارش پیپ، دکمه بازگشت (Undo)، شروع مجدد، پنجره پرتاب تاس اول (Roll-off) و پنجره اعلام پیروزی.
  - `BoardCanvas.tsx`: موتور رندر بوم ۲ بعدی (Canvas)، درگ و دراپ مغناطیسی، پیشخوان (The Bar)، خروج مهره‌ها و نشانگر خانه‌های مجاز.
  - `SingleDie.tsx`: کامپوننت کمکی نمایش تاس برای پنجره شروع بازی.

- **`logic/`**
  - `gameSession.ts`: ارکستریتور و مدیریت نوبت، تاس ریختن و توالی بازی بازیکن و ربات.
  - `gameBoard.ts`: نگهداری وضعیت ۲۴ خانه تخته، مهره‌های روی بار و مهره‌های خارج‌شده.
  - `boardLayout.ts`: مختصات دقیق مهره‌ها و ابعاد مرجع تخته با تناسب ۱۶:۱۰.
  - `moveValidator.ts`: مرجع قوانین بازی تخته نرد سنتی ایرانی (خانه‌های بسته، الزام ورود از بار، زدن تک‌مهره و خارج کردن).
  - `playerPath.ts`: مسیر حرکت مهره‌های سفید (از ۲۴ به ۱) و سیاه (از ۱ به ۲۴).
  - `computerAi.ts` و `advancedAi.ts`: مغز و هوش مصنوعی ربات برای تحلیل شاخه‌ها و انتخاب بهترین حرکت‌ها.
  - `dice3D.ts`: فیزیک شبیه‌سازی پرتاب تاس سه بعدی در وسط تخته (با جهت پرتاب از بالا برای حریف و از پایین برای کاربر).
  - `checkerAnimation.ts`: موتور انیمیشن فیزیکی ۶۰ فریم برای حرکت قوسی مهره‌ها و پرتاب مهره خورده‌شده به بار.
  - `soundManager.ts`: مدیریت پخش افکت‌های صوتی با وب‌آدیو بدون باگ تداخل.
  - `models.ts`: تایپ‌ها، تعاریف داده و مدل‌های اولیه.

## 💡 نکات کلیدی برای AI توسعه‌دهنده در پروژه جدید:
1. هیچ نیازی به نصب پکیج‌های اضافی نیست؛ این ماژول تنها با **React** و استایل‌های استاندارد سازگار است.
2. چنانچه پروژه مقصد از **Tailwind CSS** استفاده نمی‌کند، کلاس‌های ظاهری کامپوننت از Flexbox استاندارد استفاده می‌کنند و تنها کافیست ابعاد والد (`width` و `height`) مشخص باشد.
3. تمام محاسبات صفحه به صورت ریسپانسیو و متناسب با ابعاد صفحه نمایش کاربر مقیاس می‌شوند.
